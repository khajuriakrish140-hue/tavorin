Work

TCP port scanner

A command-line TCP connect scanner written in Python. It checks ports 1 to 1024 by default across a pool of 100 worker threads, so a scan takes seconds, and reports each port as open, closed or filtered. It can grab banners from open ports, shows a live table and progress bar in the terminal, and exports results as JSON or HTML.
